产品身份

什么是食品级一水磷酸二氢钙？

一水磷酸二氢钙（MCP或MCPM），标准化名称为磷酸二氢钙，是水合酸式磷酸钙，分子式为Ca(H2PO4)2·H2O。JECFA 将该一水合物列为 CAS 10031-30-8，INS 编号为 341(i)。

JECFA列出缓冲,坚硬,螯合剂,膨松,面团调理,纹理,酵母食品和营养功能。在化学膨松中,水使MCP磷酸二氢钙和碳酸氢钠发生反应,释放出二氧化碳;生产成功与否取决于准确的中和和气体释放特性。

评估烘焙性能，不能只看商品含量

中和值和反应时间

中和值(NV)表示100份膨松酸中和碳酸氢钠的质量。行业参考通常给出MCP磷酸二氢钙一水合物NV在80左右,但合同价值和方法必须来自所提供的确切等级。

酸与碳酸氢盐平衡

使用认证的 NV 计算起始比率。然后在测量成品pH值、味道、颜色和残余碱度/酸度后进行调整。

早期气体释放

MCP 磷酸二氢钙单水一般被筛选为快速作用的酸。在结构固化之前,在混合、转移和实验室小试保持过程中追踪气体损失。

混合酸系统

当需要炉级气体时,MCP 磷酸二氢钙可用缓慢膨松的酸进行评估。从各自的NV计算每种酸,并通过烘烤测试确认总反应。

等级变量

粒径、涂层/处理、湿度、温度、水的可用性、面团粘度和成分顺序可能会改变表面反应特征。

不要发布通用剂量NV是一种化学量表的起始工具,而不是成品配方。面粉、可可、乳制品固体、酸、盐和工艺条件也会消耗或增加酸度并改变气体保留。

从实验室到生产线的验证批准

如何在烘焙系统中确定 MCP

  1. 1

    锁定身份

    要求食品级单水合物,CAS 10031-30-8,来源标准,标签,签名规格和批次可追溯性。

  2. 2

    从认证的 NV 获得平衡

    从提供的品级计算起始碳酸氢盐比例,同时考虑其他配方中的酸和碱成分。

  3. 3

    测量反应时间

    使用匹配的水、温度、混合器和保持时间来跟踪早期和总气体释放,而不仅仅是最终的含量测定。

  4. 4

    运行产品试验

    对照已批准的基准，比较体积、气孔、对称性、摊展程度、颜色、pH、质构与口感。

  5. 5

    干混料加严条件试验

    测试湿度、包装、储存时间、分离和过早的酸-碳酸氢盐反应。

  6. 6

    设置接收控制

    同意身份、Ca 含量测定、杂质、NV/反应、颗粒分布和COA字段与方法和变更控制。

储存与操作

保护吸湿性 MCP 和预混料

  • 不含水分经批准的袋子应密封、干燥并防止穿孔、污染和潮湿空气。
  • 使用来源条件所提供的指导说明中说明应在30°C以下的凉爽、干燥、通风的环境中储存;请确认当前规格中的保质期和限制。
  • 预混料稳定性与碳酸氢钠混合后,控制湿度和包装,以减少过早反应和活性损失。

食品级MCP常见问题

此页面是单水或无水MCP磷酸二氢钙?

本网址现主要涵盖食品级一水磷酸二氢钙, CAS 10031-30-8。百泉化工为无水 MCP 磷酸二氢钙, CAS 7758-23-8 设有单独页面,以避免水合形式和搜索意图之间的混淆。

MCP 磷酸二氢钙是否总是一种快速作用的膨松酸?

无涂层MCP磷酸二氢钙单水合物一般被筛选为快速作用,但实际配置取决于等级、粒径、处理/涂层、湿度和工艺。商用涂层无水 MCP 磷酸二氢钙可设计为缓慢释放,请索取反应数据。

什么是中和值?

NV是碳酸氢钠中和于100份膨松酸的质量部分。一个行业参考通常列出了大约80的MCP磷酸二氢钙单水合物,但采购和配方必须使用认证值提供的等级。

所提供的规格是否符合JECFA?

不符合书面说明。所提供的铅限值为5 mg/kg,而JECFA的最高限值为4 mg/kg,损耗测试标签相互冲突,而且若干方法未定义。需要更正具体货源的规格。

MCP RFQ 应包括哪些内容?

说明食品级单水合物,CAS 10031-30-8,目标标准,NV和反应特征,粒径,烘焙应用和工艺,数量,25公斤包装/托盘需求,目的地,国际贸易术语和证书。
