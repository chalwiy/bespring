Buyer questions

Questions from International Buyers

Where can I compare different phosphate grades?

Start with the phosphate directory. Use the product or application page for the intended food, feed or industrial grade. Confirm the specification and source before ordering.

What details are useful for a quotation?

Send the material name, grade, specification, estimated quantity, packaging, destination and required documents. Include the application if you are comparing several grades.

How should I request quality or certification documents?

Name the document, product, grade and intended market. If the request concerns an existing order, include its lot or quote reference. See the quality documentation guide.
