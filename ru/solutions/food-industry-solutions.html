Выберите руководство и пищевую спецификацию для выпечки, мяса, рыбы, молочной продукции или напитков.

Назначение и исходные данные

Определите категорию продукта, рынок сбыта, параметры процесса и технологическую функцию ингредиента.

Руководства по применению

  • Выбор фосфатов для изделий из мяса и птицы
  • Выбор пищевых фосфатов для рыбы и морепродуктов
  • Выбор фосфатных разрыхлителей для выпечки
  • Выбор фосфатных солей-плавителей для плавленых сыров
  • Выбор ингредиентов для рецептур напитков
  • Выбор ингредиентов для соусов, начинок и готовых блюд

План сравнения

Выберите руководство для вашей задачи. Сравните допустимые марки пищевого качества с контрольной рецептурой в реальном процессе.

Сырьё и марки для оценки

  • Пищевые ингредиенты и добавки

Измеряемые критерии

Установите измеримые критерии, например объём для выпечки, потери для мяса и рыбы или стабильность для напитка.

Условия применения и требования

Сверьте допустимость применения, условия внесения и правила указания ингредиента в маркировке для конкретной категории и рынка.

Для рынка ЕАЭС проверьте актуальные редакции регламентов и применимые изменения. Для других рынков ориентируйтесь на правила страны сбыта.

  • ТР ТС 029/2012 о пищевых добавках для рынка ЕАЭС
  • Разъяснения ЕЭК по изменениям к ТР ТС 029/2012
  • ТР ТС 022/2011 о маркировке пищевой продукции для рынка ЕАЭС
  • Кодекс Алиментариус: справочная база по добавкам и категориям пищевых продуктов

Документы для оценки

Запросите пищевую спецификацию и сертификат анализа (CoA) партии, которую будете оценивать. Сверьте наименование вещества, методы испытаний и согласованные пределы.

Запрос для вашей задачи

Опишите применение и требуемую марку. Укажите ожидаемый объём закупки, перечень документов и место поставки.
