肥料の選択は必須の栄養素の比率、容解性、水質、作物の段階、適用方法および地方の農業の規則によって決まります。

01 / FERTIGATION

認証システム

適切な灌漑および投薬システムによる栄養素の配達のための隣酸塩の原料の選択。

 02 / FOLIAR

フォリア栄養

濃度、作物の感受性およびスプレーの両立性の周りに考慮される水溶性の栄養素の入力。

 03 / WATER-SOLUBLE

水溶性ブレンド

リン、カリウムおよび混合された栄養素の公式および専門肥料のための窒素の源。

 04 / SOILLESS

無土壌栽培

水質と適合性が重要となる管理された系に向けた、栄養供給源の検討。

 05 / COMPOUND

混合肥料の生産

栄養素の分析、プロセス ルートおよび完成品のフォーマットのまわりで選ばれる隣酸塩の原料。

 06 / SPECIALTY

スペシャルティクロッププログラム

園芸、温室生産および段階固有の給餌プログラムのためのターゲットを絞られた栄養素の選択。

栄養素ターゲットから始める

作物の栄養の目標のまわりで造って下さい

有用な肥料調達要件は、リン酸塩源を選ぶ前に栄養供給量と施用上の制約を明確にします。

Phosphorusの供給

リンスコントリビューションがターゲット分析に集中する栄養素配合をサポートします。

カリウムの供給

窒素を自動添加することなく、リンベースのシステムにカリウムを構築します。

窒素 + リン

必要な窒素からリン酸アンモニウムプロファイルの周囲のリン酸アンモニウムパスウェイを選択します。

容解性及び配達

等級、分解の行動および不純物は目的の肥料プロセスに限界を限ります。

互換性とpH

最終製品選択の前に水化学、タンク パートナーおよび公式pHを見直して下さい。

栄養素の経路

リン酸塩のソースをシステムに一致させます

これら5種類の原料は、栄養供給と配合の異なる選択肢を示しています。これは用途ガイドであり、製品仕様書や農業上の施用量の推奨ではありません。

P + K / NO NITROGEN

リン酸二水素カリウム (MKP)

リンおよびカリウムの源は水溶性の肥料、fertigationおよび窒素なしの栄養素の入力が好まれている葉状形成のために考慮しました。

ディスク:等級、容解性、水質および意図された適用。

P + K / ALKALINE PROFILE

リン酸水素二カリウム (DKP)

MKPの異なるpHプロファイルと一緒にリンとカリウムを要求する製剤のためのカリウムリン酸塩経路。

ディスク:配合pH、互換性および栄養素ターゲット。

N + P / MONOAMMONIUM

リン酸二水素アンモニウム (MAP)

栄養成分比と工程特性が必要な配合に合う肥料系で使用する、窒素とリンの供給源です。

ディスク: 栄養素の分析、等級、プロセス ルートおよびフォーマット。

N + P / DIAMMONIUM

リン酸水素二アンモニウム (DAP)

異なる窒素対リン酸コントリビューションでアンモニウムリン酸オプション, 一般的に化合物およびフィールド肥料の生産のために評価.

ディスク:ターゲット分析、造粒または混合のニーズと目的地。

SPECIALTY K + P PATHWAY

ピロリン酸四カリウム (TKPP)

適切な処方システムにおけるカリウムおよびリンの貢献のための特別なカリウムのピロホスフェートオプション、グレードおよび使用目的の要件に応じて。

Nutrient と Application Context を定義する

これらの詳細を共有して、議論は正しい隣接家族と供給オプションから始まります。

  • 作物及び段階: 作物のタイプ、成長段階および栄養の目的
  • アプリケーション: 肥料、葉状、土壌の塗布、ブレンドまたは造粒
  • 栄養素のターゲット: 必要なP、KおよびNの貢献か終了する分析
  • 水条件: 水硬度、pHおよび知られている両立性制約
  • プロダクト形態: 溶ける粉、水晶、粒状の入力または製造の原料
  • 供給: 等級、年次容積、パッキング、目的地および文書の必要性

選考の原則

栄養素のターゲット+配達方法+水化学は隣酸塩の経路を定める。

容解性、互換性、投与量、作物の応答および規制の適合性は、完成した肥料および意図された使用のために検証されなければなりません。

バイヤーの質問

よくある質問

肥料の処方薬、販売代理店および農業の入力バイヤーからの共通の質問への簡潔な答え。

肥料システムにおけるMKP、MAP、DAPの違いは何ですか?

MKPは窒素なしでリンおよびカリウムに貢献します。MAPおよびDAPは異なった栄養素の比率で窒素およびリンに寄与し、異なった公式およびプロセス特徴があります。選択は終了する栄養素のターゲットおよび適用方法に従うべきです。

肥料は、肥料や葉状の使用に適していますか?

適性は等級、容解性、不純物の限界、水質、集中、作物の感受性および他の入力との両立性によって決まります。 化学名だけ選ぶより意図したシステムを共有して下さい。

リン酸肥料はカルシウムやマグネシウム製品と混合できますか?

リン酸塩の両立性はカルシウム、マグネシウム、水硬度、集中およびpHによって、潜在的に沈殿物を引き起こします影響することができます。 互換性およびタンク混合の順序は実際の使用条件の下でテストされるべきです。

農業リン酸塩製品にどのような文書がありますか?

典型的な文書には、製品仕様、分析証明書、技術的なデータシート、安全データシートが含まれます。 在庫およびフォーマットは、製品および要求されたグレードに依存します。

Bespringは複数のリン酸塩肥料を一つの注文で供給できますか？

複数のプロダクト調達は順序の容積、プロダクト両立性、パッキング、輸送の分類および宛先条件に応じて支えられるかもしれません。 調整された供給の検討のための完全なリストを送って下さい。

どのような栄養素システムを開発していますか?

アプリケーション、栄養素のターゲット、必須の等級、容積および宛先を送って下さい。私達のチームは適したリン酸塩の供給の選択を狭く助けます。
