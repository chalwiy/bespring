產品身份

什麼是食品級一水磷酸二氫鈣？

一水磷酸二氫鈣（MCP或MCPM），標準化名稱為磷酸二氫鈣，是水合酸式磷酸鈣，分子式為Ca(H2PO4)2·H2O。JECFA 將該一水合物列為 CAS 10031-30-8，INS 編號為 341(i)。

JECFA列出緩衝,堅硬,螯合劑,膨鬆,麵糰調理,紋理,酵母食品和營養功能。在化學膨鬆中,水使MCP磷酸二氫鈣和碳酸氫鈉發生反應,釋放出二氧化碳;生產成功與否取決於準確的中和和氣體釋放特性。

評估烘焙效能，不能只看商品含量

中和值和反應時間

中和值(NV)表示100份膨鬆酸中和碳酸氫鈉的質量。行業參考通常給出MCP磷酸二氫鈣一水合物NV在80左右,但合同價值和方法必須來自所提供的確切等級。

酸與碳酸氫鹽平衡

使用認證的 NV 計算起始比率。然後在測量成品pH值、味道、顏色和殘餘鹼度/酸度後進行調整。

早期氣體釋放

MCP 磷酸二氫鈣單水一般被篩選為快速作用的酸。在結構固化之前,在混合、轉移和實驗室小試保持過程中追蹤氣體損失。

混合酸系統

當需要爐級氣體時,MCP 磷酸二氫鈣可用緩慢膨鬆的酸進行評估。從各自的NV計算每種酸,並透過烘烤測試確認總反應。

等級變數

粒徑、塗層/處理、溼度、溫度、水的可用性、麵糰粘度和成分順序可能會改變表面反應特徵。

不要釋出通用劑量NV是一種化學量表的起始工具,而不是成品配方。麵粉、可可、乳製品固體、酸、鹽和工藝條件也會消耗或增加酸度並改變氣體保留。

如何在烘焙系統中確定 MCP

  1. 1

    鎖定身份

    要求食品級單水合物,CAS 10031-30-8,來源標準,標籤,簽名規格和批次可追溯性。

  2. 2

    從認證的 NV 獲得平衡

    從提供的品級計算起始碳酸氫鹽比例,同時考慮其他配方中的酸和鹼成分。

  3. 3

    測量反應時間

    使用匹配的水、溫度、混合器和保持時間來跟蹤早期和總氣體釋放,而不僅僅是最終的含量測定。

  4. 4

    執行產品試驗

    對照已批准的基準，比較體積、氣孔、對稱性、攤展程度、顏色、pH、質構與口感。

  5. 5

    幹混料加嚴條件試驗

    測試溼度、包裝、儲存時間、分離和過早的酸-碳酸氫鹽反應。

  6. 6

    設定接收控制

    同意身份、Ca 含量測定、雜質、NV/反應、顆粒分佈和COA欄位與方法和變更控制。

儲存與操作

保護吸溼性 MCP 和預混料

  • 不含水分經批准的袋子應密封、乾燥並防止穿孔、汙染和潮溼空氣。
  • 使用來源條件所提供的指導說明中說明應在30°C以下的涼爽、乾燥、通風的環境中儲存;請確認當前規格中的保質期和限制。
  • 預混料穩定性與碳酸氫鈉混合後,控制溼度和包裝,以減少過早反應和活性損失。

採購常見問題

食品級MCP常見問題

此頁面是單水或無水MCP磷酸二氫鈣?

本網址現主要涵蓋食品級一水磷酸二氫鈣, CAS 10031-30-8。百泉化工為無水 MCP 磷酸二氫鈣, CAS 7758-23-8 設有單獨頁面,以避免水合形式和搜尋意圖之間的混淆。

MCP 磷酸二氫鈣是否總是一種快速作用的膨鬆酸?

無塗層MCP磷酸二氫鈣單水合物一般被篩選為快速作用,但實際配置取決於等級、粒徑、處理/塗層、溼度和工藝。商用塗層無水 MCP 磷酸二氫鈣可設計為緩慢釋放,請索取反應資料。

什麼是中和值?

NV是碳酸氫鈉中和於100份膨鬆酸的質量部分。一個行業參考通常列出了大約80的MCP磷酸二氫鈣單水合物,但採購和配方必須使用認證值提供的等級。

所提供的規格是否符合JECFA?

不符合書面說明。所提供的鉛限值為5 mg/kg,而JECFA的最高限值為4 mg/kg,損耗測試標籤相互衝突,而且若干方法未定義。需要更正具體貨源的規格。

MCP RFQ 應包括哪些內容?

說明食品級單水合物,CAS 10031-30-8,目標標準,NV和反應特徵,粒徑,烘焙應用和工藝,數量,25公斤包裝/托盤需求,目的地,國際貿易術語和證書。
